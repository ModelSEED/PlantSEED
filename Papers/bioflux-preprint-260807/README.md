# BioFlux preprint — PlantSEED code + reconstructions snapshot

This directory pins the exact code + data + reconstructions cited in the
2026 BioFlux preprint. All of it is reachable in a single clone:

```bash
git clone -b v2.5 https://github.com/ModelSEED/PlantSEED
```

If you don't need a specific tag and want the latest work, use `dev`.
`main` is the 2018 PlantSEED-v1 paper snapshot and does not contain any
of this v2.5-era work.

## How the annotated genomes + models were produced

Every artifact above was generated by the standalone
`plantseed_annotation` package
(`Scripts/PlantSEED_v3/Annotation/plantseed_annotation/`) at this tag,
via:

```bash
export PYTHONPATH=Scripts/PlantSEED_v3/Annotation

# Annotation — phylum auto-detected from Scripts/PlantSEED_v3/KBase/Species_Phyla.txt
# (Athaliana_TAIR10, Ptrichocarpa_v4.1 → Eudicot; Sbicolor_v3.1.1 → Monocot).
# Pass --phylum {Eudicot,Monocot,Basal} explicitly only for species not in
# that table, or use --threshold to override the per-phylum PSI floor.
for spp in Sbicolor_v3.1.1 Ptrichocarpa_v4.1 Athaliana_TAIR10; do
    python -m plantseed_annotation.cli \
        --orthofinder-results /path/to/OrthoFinder/Results_dir \
        --query-species $spp \
        --psi-cache-dir ./psi_cache --workers 16 \
        --out ${spp}_annotated_genome.json
done

# Reconstruction
for spp in Athaliana_TAIR10 Sbicolor_v3.1.1 Ptrichocarpa_v4.1; do
    python -m plantseed_annotation.reconstruct_cli \
        --genome ${spp}_annotated_genome.json \
        --out ${spp}_model.json
done
```

Defaults used:
- Roles:        `Data/PlantSEED_v3/PlantSEED_Roles.json` at commit recorded in provenance
- Complexes:    `Data/PlantSEED_v3/PlantSEED_Complexes.json` at commit recorded in provenance
- Template:     `Scripts/PlantSEED_v3/Template/PlantSEED_Biomass_Template.json` at commit recorded in provenance
- Compartments: `Data/PlantSEED_v3/Compartments/PlantSEED_Compartments.json`
- OF run:       15 species Phytozome reference set (Athaliana_TAIR10 + Atrichopoda + Bdistachyon + Creinhardtii + Csinensis + Gmax + Mdomestica + Olucimarinus + Osativa + Ptrichocarpa + Sbicolor + Slycopersicum + Smoellendorffii + Spolyrhiza + Zmays) with OrthoFinder 2.5.2 defaults (DIAMOND + MAFFT + FastTree).

## Method summary (annotation)

For each orthogroup containing genes from both the query and reference
species:

1. Classify every cross-species (q_transcript, r_transcript) pair:
   - **O** — OrthoFinder-called ortholog (accepted regardless of PSI).
   - **PAM** — paralog with PSI > per-OG per-species-pair mean PSI over
     OF-called orthologs (accepted).
   - **PAH** — paralog in an OG with no OF orthologs for this pair,
     PSI > 0.5 fallback (accepted).
   - **PRM / PRH** — paralogs below the respective baseline (rejected).
2. Aggregate transcripts to genes: PSI(q_gene, r_gene) = MAX over any
   accepted transcript-transcript pair.
3. Apply the per-phylum PSI floor (Eudicot 0.60, Monocot 0.55, Basal 0.30)
   to paralog candidates only. Ortholog (`O`) candidates pass regardless.
4. Pick the top-PSI curated ref gene per query gene; apply the
   kb_orthofinder tie-break rules (unannotated vs annotated, substring /
   compartmentalization variants, ambiguity).
5. Emit `role # compartment` function strings, feeding directly into
   `reconstruct_app_impl.py`.

Ported from
`~/Seq_Home/PlantSEED_Processing_v2/{Identify_Functional_Homologs.py,
Process_Functional_Homologs.py}` (Sam's Processing_v2 research pipeline)
into `Scripts/PlantSEED_v3/Annotation/plantseed_annotation/algorithms/psi_refined.py`.
